## Bugs found and fixed during the phase (R10: investigate surprises)
- Biopython's "email not specified" warning was still printed because its message starts with a newline and my filter pattern used `.`. Fixed with `(?s)` and a test that fails if the warning leaks.
- I had assumed NCBI's summary has a `status` field. The real record has none (`status` came back `null`). The cached metadata now stores `sourcedb` and `completeness` instead, and the cards show them. Both genomes were downloaded again with the corrected code.

## Facts that matter for Phase 2
- phiX174 is circular and single-stranded; lambda is linear and double-stranded (NCBI). The simulator draws reads from one strand of a linear string (D-017). That means no reads cross the origin of phiX174, so a few bases near the origin get slightly lower coverage than the Lander-Waterman ideal; the Phase 2 validation must account for this edge effect and say so.
- The `Genome` object exposes `.sequence`, `.length`, `.gc_fraction`, `.accession`. The simulator should take a `Genome` and nothing else.
